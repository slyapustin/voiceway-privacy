# Voiceway — Support

## Troubleshooting

**No narrations playing**
- Check the map. If there are no pins near you, try panning to a city centre — remote areas may not have nearby Wikipedia articles.
- Ensure location permission is granted: iOS **Settings → Privacy & Security → Location Services → Voiceway** → "While Using" or "Always".
- Tap **Auto Narrate** to start automatic playback.

**Audio not routing to CarPlay / Bluetooth**
- Make sure your car is paired and selected as the audio output.
- If only cloud narrations play but device voice is silent, update to the latest app version — this is a known issue that was fixed in a recent release.

**"Daily limit reached" message**
- Free cloud narrations are capped per day. Switch to **Device TTS** in Settings for unlimited free narrations (the voice is on-device).
- Limits reset daily at 00:00 UTC.

**Narration language is wrong**
- Settings → Language → pick the language you want narrations in. This also biases the Wikipedia used for newly-discovered places.
